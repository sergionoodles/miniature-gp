# Image-to-3D Handoff

A useful concept can be supplied, licensed, or created through an authorized available image tool. Read the sibling image generator for prompt patterns only when relevant.

Use a centered single object, complete silhouette, clear materials, plain background, little perspective distortion, and no cropped/hidden limbs or fused props. Characters need separated limbs and a suitable rigging stance; creatures need the posture expected by locomotion. Avoid crowded scenes, blur, and tiny texture text.

Inspect the concept before dependent 3D work. Record the actual source path, desired orientation, important silhouette/material features, dimensions, and whether visual match or structural accuracy has priority. No provider flags or command is required for this handoff.

Pure 2D UI, logos, decals, and backgrounds should remain images unless real 3D interaction is needed. Assess generated or supplied 3D outputs against the concept before rigging or expanding a family.
