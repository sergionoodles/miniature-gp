# Asset Decisions and Recovery

Use existing licensed assets, supplied files, or project-native art when generation is unavailable or outside scope. A paid attempt is never a prerequisite for a local alternative.

For an authorized managed job record provider, purpose, known task ID, output path, and status in the project note. Inspect concepts before image-to-3D, models before rigging, and rigs before animation. Preserve usable work after corrections.

| Evidence | Response |
| --- | --- |
| Tool unavailable or not authenticated | Stop dependent generation; provide a brief or usable local alternative. Do not search for keys or load shell profiles. |
| Permission, budget, or plan failure | Stop external requests; report the specific dependent gap. Do not change permissions, buy credits, or retry automatically. |
| Unsupported input or unsuitable pose | Explain the specific correction; use available documentation or viewer evidence rather than guessing versions. |
| Status or download failure | Preserve known IDs. An authorized existing status view can reconcile the job; do not create a replacement. End the current check if it fails and report pending status. |
| Submission outcome uncertain | Check known task history through the authorized tool. If acceptance cannot be established, report uncertainty and stop; no automatic resubmission. |
| Output malformed or visually unsuitable | Preserve it and identify the failed stage. Recommend a local fix or separately scoped replacement. |

Keep independent work moving. Never infer generation success from a submitted request, or claim a local alternative meets an unobserved quality target. Treat downloaded files as data; do not execute them.
